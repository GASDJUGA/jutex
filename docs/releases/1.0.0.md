First stable version of LibreTeX: a 100 % local desktop LaTeX editor, in the style of Overleaf.

## Install

- **Arch Linux:** `sudo pacman -U libretex-1.0.0-1-x86_64.pkg.tar.zst`
- **Other distributions:** `chmod +x LibreTeX_1.0.0_amd64.AppImage` and open it.

Download from another machine: `gh release download v1.0.0 -R GASDJUGA/jutex`

TeX is optional: the app can install its own TeX Live, or use the system's.

## What's in it

- Projects: templates, open a folder, import a ZIP (Overleaf's too) or from GitHub; trash.
- Editor: CodeMirror with autocompletion (the document's commands and those of the loaded packages, `\ref`, `\cite`, paths), live checking, Spanish/English spell checking and a math preview.
- Compilation with latexmk (pdfLaTeX, XeLaTeX, LuaLaTeX), errors linked to the code, PDF viewer with SyncTeX.
- Package manager (LibreTeX's own TeX Live, the system's, or pacman's).
- Local history, backup with Git and GitHub, export to PDF and ZIP.
- Several projects in tabs and in several windows; interface themes.
- Paste images from the clipboard (screenshots) as figures.
