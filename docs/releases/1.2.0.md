LibreTeX comes to **macOS** and **Windows**: the same app, 100 % local, on all three platforms.

## Install

- **Arch Linux:** `sudo pacman -U libretex-1.2.0-1-x86_64.pkg.tar.zst`
- **Other Linux distributions:** `chmod +x LibreTeX_1.2.0_amd64.AppImage` and open it.
- **macOS (Apple Silicon, 13 or later):** open `LibreTeX_1.2.0_aarch64.dmg` and drag LibreTeX to Applications. It isn't signed by Apple, so macOS blocks it the first time: on macOS 15, System Settings → Privacy & Security → «Open Anyway»; on 13 and 14, right-click the app → Open.
- **Windows 11 (x64):** run `LibreTeX_1.2.0_x64-setup.exe` (it installs for your user, without administrator rights). It isn't signed: if SmartScreen warns you, «More info» → «Run anyway».

Download from another machine: `gh release download v1.2.0 -R GASDJUGA/jutex`

TeX is optional: the app can install its own TeX Live, or use the system's (TeX Live, MacTeX or MiKTeX).

## What's new since 1.0.0

### macOS

- Shortcuts with ⌘ and a proper macOS menu; «Quit» saves before closing.
- MacTeX is found also when the app is opened from the Dock; the package manager gives the `sudo tlmgr install …` command to copy. LibreTeX's own TeX Live works on macOS too.
- Paste images (also those copied from Preview), trackpad pinch in the PDF viewer, the app's Trash (send and restore) and «Show in Finder».

### Windows

- Per-user installer, without administrator rights.
- MiKTeX as package manager (install, uninstall and update without administrator rights), besides the official TeX Live and LibreTeX's own.
- No console windows when compiling, and cancelling ends every process of the compilation.
- Paste screenshots, drag and drop from Explorer, «Show in Explorer», files with CRLF kept as they are when saving.

### On all platforms

- The file outline folds: chapters and sections collapse and expand (with the mouse or with ← →), remembered per project.
- Search is case-sensitive by default, in the editor and in the project («Aa» switches it).
- No autocompletion after `\\` (line break).
- Smooth transition when opening a project or going back home.
- Linux: dragging a tab out of the window opens a new window on Wayland too.

## Known issue (Linux)

With **WebKitGTK 2.54** and an **NVIDIA** card on Wayland, the editor text may flicker while typing (it comes from WebKitGTK; 2.52 doesn't do it). Until it's fixed: `LIBRETEX_SAFE_RENDERER=1 libretex` removes it, but draws without the GPU and is slower.
