**JuTeX in six languages:** Spanish, English, Portuguese (Brazil), French, German and Italian, in the interface and in your documents.

## Install

- **Arch Linux:** `sudo pacman -U jutex-2.1.0-1-x86_64.pkg.tar.zst`.
- **Other Linux distributions:** `chmod +x JuTeX_2.1.0_amd64.AppImage` and open it.
- **macOS (Apple Silicon, 13 or later):** open `JuTeX_2.1.0_aarch64.dmg` and drag JuTeX to Applications. It isn't signed by Apple, so macOS blocks it the first time: on macOS 15, System Settings → Privacy & Security → «Open Anyway»; on 13 and 14, right-click the app → Open.
- **Windows 11 (x64):** run `JuTeX_2.1.0_x64-setup.exe` (it installs for your user, without administrator rights). It isn't signed: if SmartScreen warns you, «More info» → «Run anyway».

Download from another machine: `gh release download v2.1.0 -R GASDJUGA/jutex`

## What's new since 2.0.0

### On all platforms

- **Six interface languages.** By default, the system's (English if the system uses another one); change it in **Settings → Interface → Language**. If you already used JuTeX, it stays in Spanish after updating.
- **New documents in their language.** The four templates (article, course notes, homework, Beamer) come in all six languages, with babel, theorem names, custom commands and sample text translated. The language comes from the interface's, from **Settings → Language of new documents**, or from the new selector in the **New project** dialog. The article template is now called «Article».
- **Compiler when creating a project.** The **New project** dialog lets you pick pdfLaTeX, XeLaTeX or LuaLaTeX (it starts at **Settings → Compilation → Default compiler**, which now applies to templates too). With pdfLaTeX, the preamble uses `fontenc` and `lmodern` instead of `fontspec`, which only works with XeLaTeX and LuaLaTeX.
- **Spell checking in all six languages**, with a new checker (`spellbook`, in Rust): dictionaries load in hundredths of a second and take much less memory (Spanish goes from half a second and 51 MB to 0.01 s and 6 MB).
- **The language of what you open:** when opening a folder, importing a ZIP or cloning from GitHub, JuTeX reads the document's babel or polyglossia and checks spelling in its language (if there's no dictionary for that language, it turns spell checking off instead of marking everything).
- **Missing language:** if a document asks for a babel language your TeX doesn't have, **Logs and errors** says which package provides it and offers to install it and recompile (with pacman's TeX Live, the command to copy), as with a missing `.sty`.
- JuTeX's own TeX Live installs all six languages from the start (about 5 MB more).
- The macOS menu, the Windows notice to close LibreTeX and «LaTeX documentation» (the wikibook in that language, or in English) follow the language too.
- The main README is now in English; the Spanish one is still in `README.es.md`.

The Portuguese, French, German and Italian translations are new: corrections are welcome in [Issues](https://github.com/GASDJUGA/jutex/issues).

## Fixes

- In Settings, selectors with long texts no longer cut them off (it happened in Spanish too, for example with automatic indentation).

## Known issues

- **Linux (WebKitGTK 2.54, NVIDIA):** when coming back to the window, the active line sometimes flickers for a moment (~0.3 s) between the old one and the new one. The page doesn't change: it's the screen.
- **Linux:** when typing an accent with a dead key (´ + o), WebKitGTK shows a frame without the accent or the letter; if the line is right at the edge of the window, it looks like a short jump.
- After a missing babel language, **Logs and errors** also shows two errors that come from it (they go away once it's installed).
