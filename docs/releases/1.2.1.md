Smoother (animations, «Loading project», a faster editor while typing) and fixes to autocompletion, the math preview and security.

## Install

- **Arch Linux:** `sudo pacman -U libretex-1.2.1-1-x86_64.pkg.tar.zst`
- **Other Linux distributions:** `chmod +x LibreTeX_1.2.1_amd64.AppImage` and open it.
- **macOS (Apple Silicon, 13 or later):** open `LibreTeX_1.2.1_aarch64.dmg` and drag LibreTeX to Applications. It isn't signed by Apple, so macOS blocks it the first time: on macOS 15, System Settings → Privacy & Security → «Open Anyway»; on 13 and 14, right-click the app → Open.
- **Windows 11 (x64):** run `LibreTeX_1.2.1_x64-setup.exe` (it installs for your user, without administrator rights). It isn't signed: if SmartScreen warns you, «More info» → «Run anyway».

Download from another machine: `gh release download v1.2.1 -R GASDJUGA/jutex`

Update by installing over 1.2.0; projects and settings are kept.

## What's new since 1.2.0

### On all platforms

- **More animations**, short and smooth like the dialogs' (with the system's «reduce motion», only a fade): when switching tabs the view comes in from its tab's side; the home sections, the side-rail panels and the history move up or down according to their place; menus, drop-downs and notices appear and leave with a transition. When switching between open projects, the current view leaves as soon as you click.
- **«Loading project»:** if a project takes a while to open, you see the logo with a bar that fills as it loads (the project, its files, the editor and the PDF); the project comes in when it's ready.
- **Typing is faster:** each letter no longer redraws the tabs, the toolbar or the outline, nor rereads the preamble (they catch up when you stop typing). Moving the cursor to another line no longer redraws the whole view.

### macOS

- **The tab no longer jumps when going from home to a project**, in full screen too: while the project came in from the side (and while it loaded), the page was slightly wider than the window, and a trackpad scroll moved everything, tabs included, until the animation ended. The fix is shared, so it applies to Linux and Windows too.

## Fixes

- `\left(` typed inside a `\left( … \right)` pair, right before its `\right`, now also adds its `\right)` (it used to be taken as that pair's closer).
- The brace closes by itself right after `^` or `_` even if something is already written after it (`x^{|}y`), to add a missing superscript or subscript.
- Math preview with commands defined with `\DeclareRobustCommand` and with your own fontspec fonts (`\newfontfamily`): a script font, like Griffiths' r, shows as `\mathscr`; `\normalfont`, `\bfseries`, `\itshape`… inside `\text{}` no longer break it.
- **Security:** importing a ZIP uses `zip` 9, which closes several vulnerabilities with crafted ZIPs (contradictory headers, fake sizes, entries that exhaust memory); downloads (LibreTeX's TeX Live, the CTAN index) use `rustls` 0.23.46, which closes four TLS alerts.
- **Security (Windows):** any user of the PC can create folders at the root of `C:\`, so another user could prepare a `C:\texlive\…` or `C:\Strawberry\…` with programs that LibreTeX ran when compiling. Now those folders are only used if they belong to you or to the system.

## Linux: the 1.2.0 flicker

The text flicker while typing with WebKitGTK 2.54 and NVIDIA (a known issue in 1.2.0) goes away with NVIDIA driver 620; nothing is needed in the app. If the app is slow after updating the driver, restart the computer: with the old module loaded, WebKit draws without the GPU.
